🔒 Atlas Studio 隐私说明

更新时间：2026-08-19 · 本页为中文完整版，如有疑问可通过下方联系方式联系我们。

本工具由 F8W（www.f8w.com）运营。联系方式：560674@qq.com。涉及个人信息处理的事宜，均可通过该邮箱联系。

2. 你的提示词（Prompt）

你粘贴进体检仪 / 配方卡 / 分镜工具的所有内容，仅在浏览器本地分析，不上传服务器，不用于任何模型训练。分享链接由你主动生成时，配方内容才以 URL 参数形式存在于链接中（不上传我们的数据库）。

3. 产品使用统计（经你同意后收集）

在你明确选择「允许匿名使用统计」后，我们收集以下最小化事件，用于改进产品：

  • page_view 页面访问
  • check_started / check_completed 开始/完成一次体检（只含统计值，如命中词条数、覆盖率）
  • evidence_viewed 查看了某个词条的证据
  • recommendation_applied 采纳了某条建议
  • export_clicked 复制了提示词/优化版/配方/分镜
  • share_created 生成了分享卡/分享链接
  • feedback_vote 词条页「一致/不一致」反馈

我们不收集提示词正文。事件在发送前经过严格白名单过滤：任何超长字段都会导致整条事件被丢弃——这是代码级保证，不是承诺。

4. 随机分析 ID

同意统计后，浏览器会生成一个随机分析标识（假名化 ID，形如 UUID），用于计算「多少人在用、是否下周还来」这类产品指标。它：不包含任何个人信息、不与账号绑定（本期无账号系统）、不跨站共享；按 90 天滚动有效期保存（超期或长期不活跃自动失效）。

5. 如何关闭

页脚「📊 使用统计」开关可随时切换为「仅本地使用」：关闭后立即停止发送一切事件，本地的随机分析 ID 同时被删除，工具全部功能不受影响。

6. 如何删除

点击上方按钮可立即清除本地的随机分析 ID。如需删除服务端已记录的、与该 ID 关联的历史统计数据，请发邮件（560674@qq.com）附上页脚显示的 ID（可在删除前复制），我们会进行处理。

本说明为产品隐私实践描述，不构成正式法律意见。
