## ❓ Why / 为什么需要它

Write "a girl in a city, cinematic" ten times and you get ten different results — because prompts are full of words that **don't do anything** and slots that were **never written**.

Other prompt libraries are collections. This project is a **methodology + dictionary + tool**:

- **Every term carries a determinism score** (0–100): the probability a mainstream model renders it as intended
- **Prompt Checker**: paste any prompt → 9-slot coverage report + determinism score, showing which words are dead weight and which slots are missing
- **Recipe Card builder**: pick terms slot by slot → one-click copy of Chinese & English prompts

## ✨ Features / 三大能力

| Feature | Description |
|---|---|
| 🔍 **Prompt Checker** | Paste a prompt → slot-by-slot scan → coverage report + determinism score + uncertain-source warnings + shareable report |
| 🧪 **Visual Recipe Card** | Pick terms across 9 slots → live card preview → one-click copy of EN/中文 prompts |
| 📚 **Atom Dictionary** | 60 terms × 9 slots, bilingual (zh/en), with scores, effect notes and examples |

## 🚀 Quick Start / 快速开始

### Install as an Agent Skill (Claude Code / Codex / WorkBuddy / etc.)

```bash
# Claude Code / Claude-style tools
git clone https://github.com/f8wco/prompt-atlas.git ~/.claude/skills/prompt-atlas

# Codex
git clone https://github.com/f8wco/prompt-atlas.git ~/.codex/skills/prompt-atlas
```

Then in a conversation, simply say:
> "Use prompt-atlas to check this prompt: a girl in a city, cinematic"
> "Use prompt-atlas to write a cyberpunk rainy-night car chase video prompt"

### Web demo (local)

Double-click `web/index.html` — no server needed. Includes a **🌐 中/EN language toggle**.

### Web demo (online)

The live demo is deployed automatically by GitHub Actions (`.github/workflows/deploy-pages.yml`). In repo Settings → Pages, set the Source to **GitHub Actions**; every `web/` update then ships automatically. Visit <https://f8wco.github.io/prompt-atlas/>.

## 🧱 The 9 Slots / 9 槽位模型

Lighting · Camera Movement · Shot Size · Composition · Color Grading · Style · Mood · Time · Lens & Technique

A complete prompt = Subject/Action/Scene (free text) + 9 slots (dictionary terms). **Blank slots are where the model improvises.**

## 📊 Determinism Score / 确定性分数

| Score | Meaning | Examples |
|---|---|---|
| ≥ 80 high | Physical facts any mainstream model renders reliably | golden hour (92), close-up (90), time-lapse (88) |
| 60–79 mid | Common styles/techniques; varies between models | film grain (75), handheld (65) |
| < 60 low | Abstract, compound, drift-prone concepts — often dead weight | cinematic (55), rule of thirds (55) |
