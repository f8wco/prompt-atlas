# 冷启动策划 LAUNCH · Cold-Start Plan

> 冷启动是生死关：**没图库没用户，没用户没贡献，没贡献没图库**。
> 核心策略一句话：**前 200 张图自己造，后 800 张让用户抢着给你造。**
> Cold start is the make-or-break moment. Strategy in one line: build the first 200 images yourself, and make users fight to build the next 800 for you.

---

## 一、图库自动采集：4 条管道 / Collection Pipelines

### 管道 1：程序化批量自生成（第 1–2 周打底）/ Batch Self-Generation
- 脚本把 `core.json` 当生产队列：每个词条 × 每个模型 → 自动生成 3 个候选
- ffmpeg 抽中间帧 → CLIP 语义匹配 + 美学评分自动质检 → 入库待抽检
- **成本控制关键**：大部分词条（光线、调色、运镜）不需要最贵模型：
  - 开源模型（HunyuanVideo / Wan2.1 / LTX-Video）租 GPU 跑 60%
  - 国内平台免费额度覆盖 20%
  - Runway/Sora 等 API 只跑「非它不可」的电影术语词条
- 总成本控制在**千元级**（约 21 核心词 × 5 模型 × 3 候选 ≈ 315 条视频）

### 管道 2：CC0 真实素材匹配（免费）/ CC0 Footage Matching
- Pexels / Pixabay 免费视频里本来就有完美的运镜、光线样例
- 用 CLIP 把素材帧与词条语义自动配对
- 特色功能：「这个词在真实电影里长这样 vs 在 AI 里长这样」双图对比

### 管道 3：种子用户悬赏认领（第 3–8 周主力）/ Seed-User Bounty Claims
- 缺图词条挂**悬赏榜**明码标分
- 100 个种子用户（即刻/小红书/Discord/Reddit 招募），每人认领 10 个词
- 署名权从第一天就给：创始绝版徽章 + 90 天双倍积分（详见 `ECONOMY.md`）

### 管道 4：「一词成名」周赛（永久自采集引擎）/ Weekly Challenge
- 每周指定一个缺图词条比赛，冠军帧直接成为官方样图 + 署名 + 200 积分
- 一箭四雕：采到图、验了词、活了社区、参赛作品本身就是传播素材

## 二、第一批用户：3 个钩子 / First Users: 3 Hooks

| 钩子 Hook | 说明 Description | 优先级 Priority |
|---|---|---|
| 🔍 **提示词体检仪** | 贴入提示词 → 10 秒输出「9 槽位缺漏报告 + 确定性得分」；「分享我的确定性得分」自带病毒传播 | 🥇 最先做（开发量最小、传播最强） |
| 🧪 **视觉配方卡生成器** | 免登录网页版，选词看图、实时拼卡、一键导出；每张导出的卡都是带链接的流动广告 | 🥈 |
| 🎬 **一词一拆解短视频** | 每周 60 秒：「希区柯克变焦是什么 → AI 里怎么写 → 效果对比」；Before/After 是 AI 视频领域验证过的最强传播格式 | 🥉 |

**发布渠道**：Product Hunt、即刻、V2EX、Reddit r/StableDiffusion r/aivideo、Discord 社群、微信公众号、小红书/抖音/B站。

## 三、8 周节奏 / 8-Week Timeline

| 周 Week | 动作 Action |
|---|---|
| W1–2 | 批量造图（管道 1+2，目标 60% 覆盖率）+ 搭体检仪 |
| W3 | 发布体检仪抢流量（管道 3 招募同步启动） |
| W4 | 配方卡生成器上线；内容营销（一词一拆解） |
| W5 | 悬赏榜上线（管道 3 主力） |
| W6–7 | 「一词成名」周赛开赛（管道 4 运转） |
| W8 | 开放提交 + 积分上线；目标 1000 注册用户 |

**北极星指标 / North-star metric：配方卡分享率。**

## 四、预算估算（管道 1）/ Budget Estimate

| 项目 Item | 成本 Cost |
|---|---|
| GPU 租用（开源模型跑 60% 词条） | ¥300–500 |
| 国内平台免费额度 | ¥0 |
| 高价 API（电影术语词条 10%） | ¥200–400 |
| 人工抽检（兼职） | ¥200 |
| **合计 Total** | **约 ¥700–1100** |

## 五、四个避坑 / Four Pitfalls

1. **别先做社区再做工具** —— 单人无价值的社区是无源之水；先让工具自己说话
2. **60% 图库覆盖率就发布** —— 缺口挂悬赏反而变成参与入口，别等「完美」
3. **种子用户宁缺毋滥** —— 双倍积分招刷子，一律人工审核
4. **版权红线** —— 真实电影片段只作参考展示、绝不进下载库
